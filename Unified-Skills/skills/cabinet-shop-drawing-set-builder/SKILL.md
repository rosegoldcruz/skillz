# Cabinet Shop Drawing Set Builder

Goal: help the user plan a full cabinet drawing set a shop can price and build, and avoid the missing info that causes rework. This skill plans and outlines. It does not draw CAD files itself.

## Step 1: Collect inputs first

Ask for anything missing before outlining. Do not invent answers.

- Project type (kitchen, vanity, wardrobe, built-in, commercial casework)
- Construction style: face frame or frameless
- Standard material thicknesses the shop uses
- Quality grade (Economy, Custom, Premium)
- Site measurements, and whether field dimensions were taken
- Appliance spec sheets, plumbing and electrical locations
- Hardware preferences (brand, hinge, slide, pulls)
- Finishes and the finish schedule
- The shop's title block or drawing standard, if any
- Software the shop's machine files will come from (the set must match it)

## Step 2: Outline the sheets

| Sheet | Must show |
|---|---|
| Plan | Every run tied to walls, fillers and scribes at crooked walls, appliance clearances |
| Elevations | Every run, door and drawer layout, tags, overall dimensions |
| Sections | One per cabinet type: box thickness, back panel, shelves, drawer stack, toe kick, hinge clearance, wall and counter junctions |
| Front views | Door and drawer sizes, overlays, reveals |
| Interiors | Shelves, dividers, pullouts, rods |
| Hardware schedule | Manufacturer part numbers, quantities |
| Details | Corners, scribes, special joinery, custom features |
| Notes | Blocking in walls, items by others (appliances, outlets, TVs), verify-in-field dimensions |

Optional: a cut list, if the shop wants one.

## Step 3: Build in the right habits

- Use one unit-numbering system everywhere (plan, elevation, schedule).
- Put a legend on every sheet that uses symbols.
- Add a quantity table when a unit repeats elsewhere in the project.
- Show hinges and pulls together so they cannot collide.
- State finish for faces, edges and interiors.
- Mark grain direction on matched runs.
- On resubmittals, add a revision cloud around every change.
- For commercial jobs, expect an architect's submittal review before fabrication.

## Step 4: Produce a drafting brief

When asked, write a short brief the user can hand to a drafter. Use this layout:

1. Project summary (one short paragraph)
2. Construction style, grade, materials
3. Sheet list from Step 2, marked with what is still missing
4. Hardware and finish notes
5. Open questions

Keep it in plain words. Flag every assumption as an assumption.

## Common reasons sets get sent back

Mention these when relevant: no field dimensions, hinge and pull clash, grade mismatch, drifting unit numbers, no revision cloud, finish left open.
