# Cabinet Drawing Review Checklist

Goal: catch mistakes on paper, before they get cut in wood. A wrong number on a drawing turns into a wrong cabinet on site.

## How to run a review

1. Ask what you are reviewing: kitchen, vanity, wardrobe, commercial casework. Ask for the floor plan and appliance specs if they were not provided.
2. Go through the sections below in order.
3. Report findings in a short list: **Problem**, **Where**, **What to ask for**. Be specific.
4. Separate real errors from questions. If you are not sure, say "this needs a check," do not state it as a fact.
5. Never say a drawing is approved. Only the user decides. Remind them to sign off in writing.

## A. Set completeness

Does the set include all of these?
- Dimensioned plan tied to the walls, with fillers and scribes shown
- Elevation of every run (not just the main one)
- Vertical section for each cabinet type
- Front views with door and drawer sizes, overlays and reveals
- Internal layouts (shelves, dividers, pullouts, rods)
- Hardware schedule with part numbers
- Site notes (blocking, appliances and outlets by others, "verify in field")
- Legend for all symbols

A set with elevations but no sections is not complete.

## B. Dimensions

- Total run lengths match the wall, with tolerance
- Cabinet widths, heights, depths match the plan
- Base and upper heights, and the gap between them
- Appliance openings include ventilation clearance
- Toe kick height and setback
- Corner cabinets account for the corner post
- Units are clear (metric vs inch) and the scale is stated
- Field dimensions were actually taken, not just copied from an architect's plan

## C. Consistency across sheets

- Door and drawer patterns match between plan and elevation
- Door swing (hinge side) is correct
- Unit numbers match everywhere. B-04 on the plan should not be 4B on the elevation
- Quantities in tables match what is drawn

## D. What every cabinet should state

- Overall width, height, depth and interior clear size
- Case material and thickness (plywood, particleboard or MDF)
- Face material and grain direction
- Edge treatment on all exposed edges
- Back panel thickness and how it is held
- Toe kick height, setback, integral or applied
- Filler and scribe allowances at walls and ceilings
- Reveals between doors, drawers, and at run ends
- Shelf thickness, pin spacing, fixed or adjustable
- Drawer box construction and slide type with clearance
- Hinge type and cup position, checked against the pull
- Countertop substrate, overhang, backsplash junction
- Wall fastening, including blocking the shop cannot see
- Finish: which faces, and what happens to edges and interiors

## E. Biggest repeat offenders

Rank these first when time is short:
1. Missing scribe allowance. Walls are not square, and a cabinet cut to the nominal size arrives too wide.
2. Grain direction not marked on matched runs.
3. Field dimensions never taken.
4. Hinge and pull in the same space.
5. Grade mismatch (spec says Premium, drawings show basic joinery).
6. Finish left open (faces only).
7. No revision cloud on resubmittals, so the reviewer cannot see what changed.
8. Symbols with no legend.

## F. Approval process

1. Review the preliminary set against the floor plan.
2. Send all comments in one consolidated list, not scattered messages.
3. Check the revised set and confirm every comment was handled.
4. Sign off in writing with a date, saying production may start.
5. Keep the signed set as the record for inspection and any dispute.

Never approve verbally. Never sign a drawing that has a known unresolved error, even a small one.

Tip for the user: ask the maker to walk through the drawing. If they cannot explain it, that is a warning sign.
