# Cabinet Spec and Tagging

Goal: explain how cabinets get identified and specified, in plain words. Define each term the first time.

## Part 1: AWI Casework Design Series (CDS) tags

AWI = Architectural Woodworking Institute. It publishes standards for how casework is built. Its CDS system gives each standard cabinet a short code so the drawing does not have to dimension every box from scratch.

How a tag looks: a small diamond (a square turned 45 degrees). The number in the middle is the cabinet type. Three numbers below it are width, height and depth.

Cabinet type series:

| Series | Cabinet type |
|---|---|
| 100 | Base cabinets without drawers |
| 200 | Base cabinets with drawers |
| 300 | Wall-hung cabinets |
| 400 | Tall storage cabinets |
| 500 | Tall wardrobe cabinets |
| 600 | Library cabinets |
| 700 | Moveable cabinets |

Rules to know:
- CDS cabinets are meant to be Type A construction, with finished ends built in and scribes to the wall not wider than 1 1/2 inches.
- If no standard cabinet fits, pick the closest one and add the letter **M** (modified). Example: 301M is a modified 301 wall cabinet.
- Extra features can go in a note line under the tag, like "Roll-Out Shelf." Keep the note short and specific.
- The tag only works if the shop knows the AWI standard. Confirm the shop works to AWI before relying on tags.

Open question to flag, not guess: on full-overlay frameless cabinets, do you dimension the depth to the box or to the finished depth with field-applied trim? One gives the shop a box size, the other gives the finished size. State which one the drawing uses.

## Part 2: AWI quality grades

| Grade | Meaning in plain words |
|---|---|
| Economy | Bare minimum. Simple butt joints, painted particle board. For work nobody sees. Rarely used. |
| Custom | Good quality with a clear level of control over materials, work and install. Fits most high-quality work. |
| Premium | Highest level. Thicker parts, better frame construction, dovetail drawer boxes, careful veneer layup. For the showpiece areas. |

Common mistake: the spec says Premium but the drawings show basic shop-standard joinery. Make sure the drawings and the grade agree.

Do not decide the grade for the user. Explain the three and ask what level the project needs.

## Part 3: Writing a clear spec

A drawing shows what is built. A spec says how it is made. A set needs both.

**Materials**
- Name the case material, thickness and type separately from the door material. Example format: "18 mm particleboard, white melamine" for boxes and "18 mm MDF, matte lacquer" for doors.
- For wood, name the species, the cut, the finish, and how much grain and color variation is acceptable.
- Mark grain direction with arrows on matched runs.

**Color**
- Use a color code (RAL, NCS, or a brand paint code) or an approved physical sample.
- Never use vague words like "warm white."

**Hardware**
- Name brand, model and key features. Good: a named concealed hinge with opening angle and soft-close, or an under-mount full-extension soft-close slide with a load rating.
- Bad: "soft-close hinges." That leaves the brand choice to the shop.
- Check that the hinge and the pull do not land in the same spot.

**Finish**
- Say which faces get finished, and what happens to edges and interiors. Leaving edges and interiors open is a top reason sets get sent back.

**Construction style**
- State face frame or frameless up front. Many dimensions depend on it.

## How to answer the user

- Explain the idea first, then show the format.
- When asked to write a spec, ask for anything missing (grade, materials, hardware brand, finish) rather than inventing it.
- Say clearly when something depends on the shop or the project standard.
